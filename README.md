# Portfólio — Mateus Althiere

Site de portfólio pessoal, em HTML/CSS/JS puro.

## Estrutura

- `index.html` — marcação e conteúdo das seções
- `styles.css` — estilos
- `script.js` — filtro de categorias do portfólio

## Como rodar localmente

Basta abrir o `index.html` no navegador, ou servir a pasta com um servidor estático simples:

```bash
npx serve .
```
